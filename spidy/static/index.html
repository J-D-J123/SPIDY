How the models and approvals work
The guide suggests a direction; the executor proposes an action. Rejected drafts go back to the guide for a correction. The conversation shows their actual replies and Spidy’s checks.
Review each action with Approve & run, or enable Auto-approve next steps. Auto-approval runs commands with your local user permissions, including local changes, while this page stays open. Refreshing or switching assessments turns it off. Turning auto-approve on starts or resumes planning. It stays on while waiting for a valid action and when you send context. Blocked drafts never execute. Turn it off or click Stop to pause automatic execution.

A transparent first pass
Spidy runs deterministic security checks against a bounded crawl. Focus keywords select check categories; no language model receives your target or findings.
It inventories reachable TCP services and advertised software versions on the target hostname, follows server-rendered HTML links, inspects headers, forms, and TLS, and can send limited GET input probes.
Known-vulnerability lookup is off unless you enable it; it sends only product and version names to NIST NVD.
Other origins are blocked before DNS resolution. Approving a discovered origin starts a new scan and preserves the earlier report.
