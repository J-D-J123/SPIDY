What Spidy does

Evidence-based findings you can follow and verify.

Every finding carries a severity, the affected URL, the evidence behind it, an explanation, a suggested fix, and an OWASP reference. The analysis is local and rule-based — it organizes what it observed rather than inventing exploitability.

Local & privateNo keys or accounts. The only outbound traffic besides the target is an optional NVD lookup you can switch off.
Scope-aware approvalsEvery request, redirect, and port check is matched against scope before DNS. New origins become approval requests.
Service inventoryOpen ports, banners, and advertised versions. Uses nmap -sV when installed, pinned to the authorized address.
Reports you can shareDownload each assessment as PDF, Markdown, or JSON with the full request log. Query values are redacted.
Optional local LLMPoint Spidy at a model you pull with Ollama for a site-specific write-up. Nothing goes to a hosted service.
Deep scans & AutopilotRun nuclei, nikto, ffuf and more on demand, or let a local model propose a step — each run needs your approval.

Assessment checks

Fourteen checks, each a signal to verify — not proof of exploitation.

Passive mode retrieves and inspects pages. Active probes and bounded path discovery are separate opt-ins. The defaults shown below are what a new scan starts with.

Get started

Clone it, then run it locally. Requires Python 3.10 or newer.

1. Clone the repository
git clone https://github.com/J-D-J123/SPIDY.git cd SPIDY
2. Install the scanners (optional)
bash install-tools.sh # Linux / macOS install-tools.bat # Windows

Drops nuclei, nikto, ffuf, wafw00f and more into ./tools/bin with no sudo. The core checks work without this step.

3. Start the dashboard
python3 -m spidy serve

Then open http://127.0.0.1:8765, enter a target you're authorized to test, confirm permission, and start.

Prefer the command line?
python3 -m spidy scan https://your-authorized-site.example --authorized

Writes a report and a PDF next to it.

Evidence you can follow

  1. Bounded discovery
  2. Focused checks
  3. Findings and full activity log
No external AI service. No account needed.

What it is not

An initial assessment tool, not a replacement for a manual penetration test. It does not execute JavaScript, authenticate, or prove SQL injection, XSS, or CSRF. No finding does not mean no vulnerability.
